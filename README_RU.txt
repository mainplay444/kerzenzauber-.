KROIZAUBER — INSTALLATION (GitHub Pages)

Dateien: index.html, main.css, script.js

1. Lade alle drei Dateien in den Hauptordner deines GitHub-Repositories hoch.
2. Dateinamen müssen exakt so lauten: index.html, main.css, script.js.
3. Commit changes und подожди завершения GitHub Pages deployment.
4. Открой сайт в приватной вкладке/обнови страницу без кэша.

ВАЖНО ПРО ОПЛАТУ
В прежнем проекте найден Stripe URL, содержащий /test_. Это тестовый URL, не действующая live-оплата. Корзина полностью удалена. На карточке каждого товара есть отдельная кнопка покупки, ведущая на ссылку этого товара. Тестовая ссылка Stripe не используется как действующая оплата. Чтобы включить реальные платежи, создай и проверь live payment link в Stripe и замени тестовый URL в script.js на подтверждённую ссылку. GitHub Pages не хранит секретные ключи; не добавляй secret API keys в JavaScript.

КОНТАКТЫ
Корзины на сайте нет. Каждый товар покупается отдельно по собственной ссылке на торговую платформу. У товара с тестовой Stripe-ссылкой покупка заблокирована до настройки настоящей Live-ссылки. Контактная форма открывает почтовое приложение.

ФОТО
Сохранены прежние URL фотографий. Если внешний хостинг удалил фото или URL не является прямой ссылкой на изображение, карточка покажет визуальную заглушку. URL для фотографии ёлочки в старом проекте выглядел как домен без пути к файлу, поэтому его необходимо заменить на прямую ссылку изображения.
