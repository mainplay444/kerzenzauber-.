KROIZAUBER — ИНСТРУКЦИЯ НА РУССКОМ

Файлы сайта:
- index.html — структура сайта.
- main.css — внешний вид и адаптация под телефон.
- script.js — товары, корзина, избранное, фильтры и две мини-игры.

КАК ОПУБЛИКОВАТЬ НА GITHUB PAGES
1. Открой свой репозиторий GitHub, который подключён к kroizauber.com.
2. Нажми Add file → Upload files.
3. Загрузи index.html, main.css и script.js из этой папки. Можно также загрузить README_RU.txt.
4. Если GitHub спросит, замени старые файлы этими новыми.
5. Внизу нажми Commit changes.
6. Подожди несколько минут и открой https://kroizauber.com. Если старый сайт остался, обнови страницу без кэша или проверь GitHub Pages.

КАК ИЗМЕНИТЬ EMAIL
Открой script.js и найди строку:
const SHOP_EMAIL = 'tatansavenok35@gmail.com';
Замени адрес внутри кавычек на нужный. Этот адрес используется и для корзины, и для контактной формы.

КАК ИЗМЕНИТЬ ТОВАРЫ И ССЫЛКИ
В начале script.js есть массив const products = [...]. У каждого товара есть поля name, price, description, image и link.
- name — название товара.
- price — цена в евро (например, 5.00).
- image — прямая HTTPS-ссылка на фотографию.
- link — ссылка на объявление Vinted или другую страницу покупки.
После изменений сохрани файл и снова загрузи его в GitHub.

ВАЖНО ПРО КОРЗИНУ И ОПЛАТУ
Корзина умеет хранить несколько товаров, менять количество и считать сумму. В корзине нужно указать корректный e-mail. Кнопка подготавливает текст заказа и показывает варианты: открыть Gmail с готовым письмом или скопировать текст вручную в любую почту. Письмо нужно самостоятельно отправить. Это НЕ настоящая онлайн-оплата и НЕ подтверждённый заказ.
Ссылки Vinted ведут на страницы отдельных объявлений. Наличие возможности купить несколько разных объявлений одной оплатой зависит от Vinted и самих объявлений. Последняя ссылка Stripe из исходного кода содержит /test/ — это тестовая платёжная ссылка, поэтому она не должна считаться готовой реальной оплатой.

ПРОВЕРЬ ПЕРЕД ПРОДАЖАМИ
- Проверь, что все фото и ссылки товаров открываются.
- Сделай пробную корзину с несколькими товарами и проверь письмо.
- Для реальной коммерческой продажи в Германии проверь требования к Impressum, Datenschutzerklärung, Widerrufsbelehrung, ценам, доставке, оплате и возрасту/правовому статусу продавца. Этот набор файлов не заменяет юридическую проверку и не подключает автоматическую оплату.
